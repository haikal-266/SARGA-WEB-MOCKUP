## 2. Catatan Keterbatasan & Sisa Non-Defect

- **ID Watermark Canvas Upload (`/auth/register`, `/gabung`) & File Upload Browser:** `chrome_devtools/upload_file` ditolak sandbox MCP (`Access denied: path ... is not within any of the configured workspace roots`), sehingga interaksi pasca-unggah file di UI browser belum dieksekusi otomatis *(endpoint backend `POST /api/v1/uploads` lulus 7 skenario tes pada [upload.test.ts](file:///c:/Users/KallKun/Desktop/Sarga%20DOC/WEB%20MOCKUP/backend/test/upload.test.ts))*.
- **DOM Script Checks:** `chrome_devtools/evaluate_script` dinonaktifkan oleh aturan izin pengguna; inspeksi overflow & aset dilakukan melalui tangkapan layar dan audit network/console.
- **DevTools Hint di Halaman Edit Barang:** Setelah perbaikan `autocomplete` pada form auth (`/auth/login`, `/auth/register`, `/gabung`), DevTools mencatat 1 hint `autocomplete` pada salah satu field form di `/edit-barang/...`.
- **Alur Penyimpanan Lokal / UI Lanjutan:** Fitur simpan edit barang ([item-edit.component.html](file:///c:/Users/KallKun/Desktop/Sarga%20DOC/WEB%20MOCKUP/frontend/src/app/features/items/item-edit.component.html)), gabung org tambahan ([gabung.component.ts](file:///c:/Users/KallKun/Desktop/Sarga%20DOC/WEB%20MOCKUP/frontend/src/app/features/auth/gabung.component.ts)), dan tambah anggota manual ([member-add.component.ts](file:///c:/Users/KallKun/Desktop/Sarga%20DOC/WEB%20MOCKUP/frontend/src/app/features/admin/member-add.component.ts)) masih tersimpan lokal di `localStorage`; [platform-directory.component.ts](file:///c:/Users/KallKun/Desktop/Sarga%20DOC/WEB%20MOCKUP/frontend/src/app/features/admin/platform-directory.component.ts) baru menyediakan tampilan daftar organisasi.
